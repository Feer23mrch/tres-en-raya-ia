# Tres en Raya con IA (Pygame) 🎮

Este es un juego clásico de Tres en Raya (Tic-Tac-Toe) escrito en Python. Utiliza **Pygame** para la interfaz gráfica y el algoritmo **Minimax** para crear una Inteligencia Artificial que es imposible de vencer.

## ¿Cómo funciona?
* Tú juegas con la **X** (color azul) y siempre tienes el primer turno.
* La máquina juega con la **O** (color rojo).
* Gracias al algoritmo Minimax, la IA siempre calculará el mejor movimiento posible. Lo máximo que podrás conseguir es un empate.

## Requisitos y cómo jugar
Para poder jugar, necesitas tener Python instalado en tu computadora y la librería Pygame.

1. Instala Pygame abriendo tu terminal o consola y escribiendo:
   `pip install pygame`
2. Ejecuta el archivo del juego:
   `python cruz.py`
3. ¡Haz clic en la pantalla para intentar ganarle a la máquina!
